# ogbg-molecular: GINE and CSNN for Molecular Graphs

Graph Isomorphism Network with Edge Features (GINE) and Cooperative Sheaf Neural Network (CSNN) implementations for molecular graph property prediction of the OGBG-MolHIV dataset.
See the [paper (Appendix A)](https://arxiv.org/pdf/1905.12265) for more details on GINE and the [paper](https://arxiv.org/pdf/2507.00647) for more details on CSNN.
